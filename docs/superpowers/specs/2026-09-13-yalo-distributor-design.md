# Yalo 作品一键分发工具：设计说明

## 目标

提供一个可部署到 GitHub Pages 的中文网页工具。使用者拖入儿童插画并填写作品信息后，网页在本机浏览器中生成五个作品平台的上传素材包及中英文发布文案。

## 适用范围

- 面向监护人为儿童创作者 Yalo 整理和同步发布插画作品。
- 支持批量图片、中文作品信息和自动生成英文发布文案。
- 首批支持站酷、涂鸦王国、Behance、ArtStation、DeviantArt；仅生成待上传素材，不登录、上传或代发至任一平台。

## 不做的内容

- 不保存账号、密码、访问令牌或儿童个人信息。
- 不把原图、作品资料或发布记录上传到 GitHub、服务器或第三方。
- 不自动点击平台发布按钮，不绕过平台的人工审核或风控。

## 架构

采用静态网页应用，部署到 GitHub Pages。所有图片读取、压缩、文件命名、文案生成和 ZIP 打包均在浏览器中完成；页面刷新后不保留已导入图片和作品资料。

页面由三个区域组成：作品信息表单、图片导入区和生成结果区。核心处理模块与界面分离：

1. `metadata` 负责校验、清理和组织标题、简介、日期、标签。
2. `copy` 根据中文作品信息生成站酷中文文案、Behance 英文文案和版权提示。
3. `package` 读取图片文件，按统一命名复制到五个独立平台目录，并生成 TXT/Markdown 文案文件和 ZIP 压缩包。
4. `ui` 仅收集输入、展示进度、错误和下载链接。

## 主流程

1. 输入中文标题、作品简介、创作日期与中文标签；英文标题和简介可选填，不填时由规则生成可编辑草稿。
2. 拖入或选择一张以上 JPG、PNG 或 WebP 图片。
3. 点击“生成分发包”。
4. 浏览器校验必填项和文件类型；不合格项在原位置说明，不生成下载文件。
5. 浏览器下载一个 ZIP 文件，顶层以 `YYYY-MM-DD_作品英文短名` 命名。
6. ZIP 内含：
   - `zcool/图片/`：原图片，按序号重命名；
   - `zcool/发布文案.txt`：中文标题、简介、标签和版权提示；
   - `tuhua/图片/`：原图片，按序号重命名；
   - `tuhua/发布文案.txt`：中文标题、简介、标签和版权提示；
   - `behance/images/`、`artstation/images/`、`deviantart/images/`：同一套原图片，按序号重命名；
   - `behance/publish-copy.md`、`artstation/publish-copy.md`、`deviantart/publish-copy.md`：英文标题、简介、标签和版权提示；
   - `README.txt`：五个平台的上传顺序、人工检查项与入口。
7. 用户自行检查隐私与版权后，将相应目录内图片和文案上传至平台。

## 文案规则

- 中文标题：保留原样。
- 英文标题：若未填写，保留中文标题并附 `— Yalo Illustration`，避免机器臆译人名、故事专名或儿童创作表达。
- 中文简介：保留原样。
- 英文简介：若未填写，生成明确标记为“请人工核对”的简短英文草稿，只转换通用字段，不虚构作品背景。
- 标签：用户输入的中文标签保留；英文标签仅转换内置通用词表中的项（例如“儿童插画”至 `children's illustration`），未命中的标签同时保留中文并标记待核对。
- 版权提示：默认写明 `© Yalo. All rights reserved.`，由监护人在发布前确认权属和授权范围。

## 隐私与安全

- 使用浏览器本地 File API，不配置图片上传接口。
- 不设置分析、广告、登录、云端数据库或作品云端历史。
- 页面明确提示：勿填写真实姓名、学校、住址、联系方式、行程或可识别儿童身份的信息。
- 下载包只在用户设备生成；页面不提供“上传至 GitHub”的按钮。

## 异常处理

- 无图片、缺标题或日期时，显示具体字段错误。
- 遇到不支持的文件类型时，列出文件名并跳过该文件。
- ZIP 生成失败时保留原输入，提示重新尝试；不宣称已生成。
- 图片数量或总大小超出浏览器安全阈值时，停止处理并提示分批导出。

## 界面与可访问性

- 首屏直接显示作品信息和图片导入，不使用营销式首页。
- 默认中文、适配手机与桌面端；正文最小 16px，常用控件最小 14px。
- 拖入区同时提供键盘可操作的“选择图片”按钮。
- 生成进度、错误和成功下载状态可被屏幕阅读器识别。

## 发布与代码仓库

- 源代码置于独立 Git 仓库，并推送到用户指定的 GitHub 仓库。
- 使用 GitHub Pages 公开部署静态构建产物。
- 仓库的 `.gitignore` 排除任何作品原图、生成 ZIP、临时文件和本地环境配置。

## 验收标准

1. 在 Chrome 或 Edge 中可选择或拖入 1–20 张 JPG、PNG、WebP 图片。
2. 填写有效信息后可下载包含五个平台目录、五份文案及说明文件的 ZIP。
3. ZIP 内图片顺序和数量与导入内容一致，未将图片发送到远端。
4. 必填字段或文件类型错误会在界面显示，且不会生成虚假成功状态。
5. 手机与桌面端均可完成导入、生成和下载。
6. 代码仓库中不包含 Yalo 的作品原图、作品内容或生成包。
