# Yalo 作品一键分发

面向儿童创作者作品整理的静态网页工具。导入图片、填写作品信息后，浏览器会在本机生成一个 ZIP，包含站酷、涂鸦王国、Behance、ArtStation、DeviantArt 的图片目录和发布文案。

## 使用方法

1. 填写中文标题、创作日期、简介与标签；英文内容可选填。
2. 导入 1–20 张 JPG、PNG 或 WebP 图片，总大小不超过 200 MB。
3. 点击“生成五平台分发包”。
4. 下载 ZIP 后，分别打开各平台目录，人工检查图片顺序、文案、版权与隐私，再自行发布。

## 隐私与版权

- 图片和作品资料只在当前浏览器内存中处理，工具不会上传、保存或自动发布。
- 不要在标题、简介或图片中公开儿童真实姓名、学校、住址、联系方式或行程。
- 默认版权提示为 `© Yalo. All rights reserved.`；发布前请由监护人确认作品权属与授权范围。

## 本地运行

```bash
npm install
npm run dev
```

## 部署

推送到 GitHub 的 `main` 分支后，GitHub Actions 会构建并部署到 GitHub Pages。仓库不会提交作品图片或生成的 ZIP 文件。
